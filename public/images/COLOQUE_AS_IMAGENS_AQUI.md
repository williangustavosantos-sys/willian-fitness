# 📸 Coloque suas imagens nesta pasta

Renomeie cada imagem conforme abaixo e cole nesta pasta:
`willian-fitness/public/images/`

---

## Mapeamento de imagens → nomes de arquivo

| Arquivo esperado | Qual foto usar |
|------------------|----------------|
| `willian-logo.png` | Novo logo esportivo "WILLIAN PERSONAL TRAINER" (fundo transparente) |
| `hero.jpg`       | Foto de braços cruzados na academia (pose séria, fundo escuro) — **HERO PRINCIPAL** |
| `about.jpg`      | Foto apontando para a câmera (pose animada, fundo academia) |
| `profile.jpg`    | Qualquer outra foto de perfil (ex: com bola medicinal) |
| `training.jpg`   | Foto assistindo o cliente no supino (bench press) |
| `action.jpg`     | Foto no cabo/polia com "COSTANZA. FORZA. RISULTATI." |

---

## Onde cada imagem aparece no site

- **`willian-logo.png`** → Cabeçalho, rodapé e páginas internas
- **`hero.jpg`** → Fundo gigante da Home (primeira coisa que o visitante vê)
- **`about.jpg`** → Seção "Sobre" na Home e página Serviços
- **`profile.jpg`** → Página "Sobre mim" (biography) e Consultoria Fitness
- **`training.jpg`** → Páginas de Personal Training e Corporate Wellness
- **`action.jpg`** → Página de Coaching Online

---

## Formatos aceitos

- `.jpg` / `.jpeg` — para fotos
- `.png` — para logo (com fundo transparente ou preto)
- `.webp` — também funciona (só mude a extensão no código se usar)

## Dica de qualidade

Para o `hero.jpg`, use a versão em maior resolução disponível.
O fundo dark da foto combina perfeitamente com o design preto do site.
